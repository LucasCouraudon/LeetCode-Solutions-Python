# LeetCode Solutions - Python

Ce dépôt contient mes solutions aux problèmes de la plateforme **LeetCode**, synchronisées automatiquement grâce à l'extension **LeetHub**.

## 📊 Objectifs
- Maîtriser les structures de données (HashMaps, Arbres, Graphes).
- Optimiser la complexité temporelle $O(n)$ et spatiale $O(1)$.
- Préparer les entretiens techniques en pratiquant quotidiennement.

## 🛠️ Configuration
- **Langage principal** : Python
- **Outil de synchronisation** : LeetHub (Firefox)
- **Structure** : Chaque dossier contient l'énoncé du problème et la solution optimisée.
